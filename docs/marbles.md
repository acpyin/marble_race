# 弹珠目录与收集

## 总览

共 58 款弹珠，分成四个互不混场的主题组（`MARBLE_GROUPS`）：纯色系 14 款、花纹系 26 款、太阳系 10 款、中国瓷器 8 款。每场先随机选一个组，再用 Fisher-Yates 从该组抽 8 颗上场（`pickMarbles`），所以一场比赛里的弹珠风格始终统一。没有「其他」兜底组，每颗弹珠都归属上述四组之一。物理、排名、UI 始终只处理 8 颗，随机化只发生在选角阶段。宝箱图鉴也按这四组分区展示。

太阳系组固定为 **太阳 + 九大行星**（水星、金星、地球、火星、木星、土星、天王星、海王星、冥王星），共 10 颗，因此太阳系专场每场从中抽 8 颗。

所有定义集中在 `src/marbles.js` 的 `MARBLE_CATALOG`，格式为 `[中文名, 颜色, 样式]`。中文名是稳定 id，收集记录与多语言译名都用它作键。

## 材质与预览

`makeMarbleMaterial` 按样式分四类：

- **透明玻璃**（crystal）：`MeshPhysicalMaterial` + transmission .96 + opacity .42 + 近零粗糙度，是全场唯一完全透明款；预览用空心高光和内壁反光表现通透感
- **透射玻璃**（glass/aurora/amber/deepsea/sakura/mint/pearl）：`MeshPhysicalMaterial` + transmission .72 + clearcoat；aurora/pearl 额外加 `iridescence` 虹彩
- **金属**（metal/chrome/rosegold/bronze）：metalness .82 + 低粗糙度 + 高环境反射
- **纹理**（其余）：canvas 程序化纹理（猫眼/玛瑙/青金石/绿松石/龙鳞/珐琅/青花瓷/汝窑冰裂/钧窑窑变/官窑开片/哥窑金丝铁线/龙泉刻花/釉里红/唐三彩流釉/冰裂/太阳米粒组织与黑子/水星陨坑/火星极冠/天王星薄雾/冥王星冰原/土星环/地球/月面/海王星/金星涡旋/拉长石/月光石/紫晶/黑曜石/脉冲星/火焰/星云/星空/千花玻璃/木星云带/蛋白石变彩/蜻蜓眼古珠/波点/大理石/吸积盘/螺旋），贴到清漆材质上；欧泊额外叠加虹彩，太阳另带 `emissive` 自发光

`makePatternTexture` 用 768×384 canvas 画纹理，种子固定所以每次生成一致。`marblePreview` 把同一张纹理（或纯色球 + 玻璃高光）映射成 96×96 的 2D 预览图，押注按钮、关注卡片、排行榜、宝箱共用这套预览，避免额外 WebGL 渲染。

## 收集机制

- `src/collection.js` 用 localStorage 键 `marble-race-collection-v1` 保存 `{ 中文名: { count, firstAt, lastAt } }`，读取时校验结构，损坏数据回退空对象
- 结算时（`main.js` 的 `checkFinish`）只有押中冠军才调用 `vault.recordWin(w.nameKey)`：新款标记为新收集并让进度徽标弹一下，旧款累加次数
- `src/vault.js` 负责右下角入口与弹窗：只列出已收集的弹珠，按最近获得排序，卡片横向平铺并自动换行，显示真实预览 + 译名 + 次数 + 首次日期；一颗都没收集时显示空状态文案 `vault.empty`
- 切换语言时图鉴自动重新渲染，文案跟随当前语言

## 扩展新弹珠

1. 在 `MARBLE_CATALOG` 加一行 `[名称, 颜色, 样式]`；复用现有样式或用新样式（新样式需在 `makePatternTexture` 加分支，纯玻璃/金属则加到对应 Set）
2. 在五份语言包的 `racers` 里补译名（键为中文名）
3. 宝箱进度分母自动变为 59（用 `MARBLE_CATALOG.length`）；README 和本文件的数字需手动更新
4. 把新弹珠名字加入四组之一的 `names` 数组（每组至少保留 8 颗，保证能单独成场；没有「其他」兜底组，必须明确归类）
5. 运行 `node tools/check-marbles.mjs` 与 `node tools/check-i18n.mjs`
