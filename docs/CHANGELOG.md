# 弹珠竞速：独立网页版

## 工程隔离

本目录独立维护浏览器源代码、依赖和构建结果。UE5 工程位于 `../Unreal/MarbleRace`，本轮修改没有写入 UE5 工程。根目录的早期网页原型也保留。

## 运行

双击本目录的 `start-or-restart.cmd`：先构建最新源代码，未运行时启动，已由该脚本启动时停止旧进程后重启。访问或刷新 http://127.0.0.1:4180/ 。也可以运行 `powershell -NoProfile -ExecutionPolicy Bypass -File tools/start-or-restart.ps1`。

运行记录和日志存放在 `.run/`。脚本停止自己记录且身份匹配的预览进程；首次可接管命令行明确属于本目录的 Vite 预览。构建失败时保留旧服务；4180 被其他程序占用或无法核对时会提示，不会结束其他 Node 程序。

在本目录执行：

```sh
npm install
npm run dev
```

打开 http://127.0.0.1:4180/ 。生产构建使用 `npm run build`，预览使用 `npm run preview`。需要支持顶层 await 和 WebAssembly 的现代浏览器。

## 当前赛道：随机组合与错层回环

赛道参数从原来的 1054 延至 2152，长度约为原来的 2.04 倍。前半程保留落孔碗、独立承接层和必要的 U 形层间衔接；后半程改成两条长直赛道，仅在远端以一个宽 U 弯连接。每场随机选择宽幅或加长回环，不再连续左右折返。下层赛道没有被上层支柱穿过；回环外侧采用低木栏和透明护板，保留观赛视野并拦截高速弹跳。

后半程把障碍分成四种固定内部组合：三列高异形木块阵、双列四排旋杆＋玻璃金属交叉漏斗、抬板连续 S 形槽＋入口导流、分流波浪＋交错挡板。四组顺序每场洗牌，组间留空白连接段。另有一组旋杆在中段的两个安全位置中随机选择，第三组固定在终端、排次槽漏斗口上游。赛道编号显示本场回环形状与木材，鼠标悬停可查看障碍组顺序。

每场只选择一种木材纹理，所有赛道板面与木质障碍共用它；新场次在浅枫木、蜂蜜橡木、樱桃木、胡桃木之间重新抽选。四种纹理分别有不同深浅、纹路密度与结疤。玻璃长管和金属杆维持真实材质，不作为木纹变体。连续 S 槽的木板肩部相对上一版再抬高 1.5 倍，槽底仍与前后赛道平接；整段木板沿前进方向以恒定坡度下行，不再按弯道弧长分段降低高度。槽宽扩大为此前的 1.3 倍，并按球到弯道中心线的垂直距离形成凹槽，避免急弯中段变窄。斜导流口后先接 14 个赛道单位的直槽，再进入约 160° 的连续弯头。弯道网格加密以免弹珠卡住。

第 11 赛段漏斗碗的入口板和下层承接板在碗口使用统一的赛道高度，避免板面一角穿进碗内；入口板提前结束，前段两侧另设木柱承重，不在碗内放支撑板。碗后窄桥的金属栏杆后移并用外扩入口引导，避免落孔后的弹珠顶住杆端。两块 S 槽导流板的末端净开口收窄至弹珠直径的 1.2 倍，接入连续直槽。

所有赛段的木栏上方均接白色半透明雾墙，碰撞护栏与雾墙同高。两只落孔碗的木质外壁向前延长，接到导流板末端并封住入口两侧的三角形缺口；雾墙只覆盖木壁上方，中央进球通道保持敞开。

开场第 2 赛段固定为木钉迷阵，原双球漏斗已经移除；第 3 赛段从错位导流门、木质分流岛、加速空廊中选择。赛段名和解说随之更新。终端旋杆阵列前移，排次槽漏斗口保持空旷。赛道和导播镜头共用正面斜俯视角度；导播切换赛段前必须确认该段有弹珠，始终从赛道中央拍摄，不向左右偏斜；手动拖动、缩放仍切换自由镜头。解说用“几个身位”“一小段”等词描述距离，实时排名仍显示数值。弹幕可横跨画面，只在经过“我的押注”摘要和实时排名面板时隐藏，默认同屏三条轨道，赛况密集时会超出轨道数继续叠加，已在飞的弹幕一定滑完整屏才消失，悬停可暂停。

启动性能：简化了会阻塞浏览器的木纹附加纹理，保留基础木纹；底板网格按弹珠半径采样，护栏碰撞合并为静态网格。独立 Chrome 的 1280×720 预览实测约 1.4 秒进入可操作界面。画面细节与性能冲突时优先保证快速打开。

验证方式：`node tools/check-new-sections.mjs` 检查三列高障碍、交叉管漏斗、S 弯角度和三组旋杆阵列；`node tools/check-extended-layout.mjs` 检查两个拓扑、随机顺序、长度、错层平面间距、路线反求和无长支柱；`node tools/check-physics.mjs <种子>` 从起跑线跑到排次槽；`node tools/check-finish-receiver.mjs <速度> <布局种子>` 检查八球高速并发入槽顺序。

## 先前版本改进记录

### 实时赛事解说与完整排名（当前版本）

解说程序改为赛况事件驱动，采用田径/自行车式的位置与间距分析、球赛式的攻防节奏表达，避免无依据的赞叹和重复泛述。每 0.5 秒保留快照，比较最近约 5 秒变化；名次稳定至少 0.7 秒再确认。重点处理前四换位、前三组相邻选手的距离增减、末两名争位/追赶/迟滞，以及所有选手提升或下降至少 3 个名次。冠军立即优先，前四完赛次序锁定后播报；末两名有独立关注节奏，前排平静时再交代整体次序。

新版语料在 `src/live-commentary-corpus.js`，16 类各 4 条，共 64 个赛况模板，另有 30 段具体特点描述。模板填入实际选手、名次、速度、现有间距、之前间距和变化米数；旧版 300 条保留归档，不再用于当前实时解说。文本最近 12 个句式避重复，常规消息间隔至少 3 秒。

播报窗口显示五行文字，继续自动换行与上滚。排名列出八颗球，每颗显示实际速度（m/s）与落后距离；区域固定 180px，每行 36px，第五名初始模糊渐隐，后三名需滚动查看，隐藏滚动条，滚到底后移除底部渐隐。排名节点复用，换位保留滚动位置，每 0.1 秒更新读数。距离沿赛道中心线累计弧长计算，包括弯曲与层间高度变化，并非两球直线距离。

已通过前排反超、三名以上升降（含倒退导致的降位）、距离缩小/扩大、末两名争位/追赶/迟滞、赛段、冠军与后续完赛检查。浏览器实际确认全部八颗速度读数、第五名渐隐及滚动展示第六至第八名且无滚动条。语音设置和语音播报继续使用。

### 程序语音解说

顶栏新增解说设置弹窗：语速倍率 0.70–1.50（步长 0.05）、每场随机/优先男声/优先女声/固定具体音色、试听与恢复默认。设置即时生效并存入浏览器，下次打开保留；试听允许在解说关闭或比赛暂停时单独播放。弹窗支持完成、Esc 与点击遮罩关闭。已在预览验证音色切换、语速调整、刷新持久保存、恢复默认及弹窗布局。

文字播报通过浏览器 SpeechSynthesis 自动转为语音；顶栏独立开关支持关闭和试听（关闭后再开启）。每场从设备提供的中文音色中随机选择男声或女声，常见音色名称用于识别；只提供一种声音时使用现有声音，不用变调冒充另一性别，无法识别时显示系统音色。没有中文声音时显示等待音色，文字播报继续运行。

开场与常规解说保持适中节奏，反超和加速提高语速，冠军冲线提高音高及音量，受阻时放缓；实际语调和自然程度依赖系统语音引擎。这是程序调节语速、音高和音量的方案，没有接入情感配音服务。参考 [SpeechSynthesis](https://developer.mozilla.org/en-US/docs/Web/API/SpeechSynthesis) 与 [pitch](https://developer.mozilla.org/en-US/docs/Web/API/SpeechSynthesisUtterance/pitch)。

最多保留一条最新待播消息，超过 6 秒的待播内容跳过，冠军优先打断，暂停、静音、离开页面立即取消。`node tools/check-voice.mjs` 已验证中文音色选择、降级、情绪参数、积压控制、冠军优先、暂停和静音。预览页面实际识别到 Microsoft Huihui 中文音色，开关状态切换通过；没有对真实发声效果进行听觉验证。

### 冠军押注与随机组合赛道

本地玩家账户初始 1000 珠，保存在当前浏览器。取消入场费，每颗候选球押注 5 珠，最多选择 4 颗，总成本为 5、10、15 或 20 珠。押中冠军奖励 `5 × 参赛弹珠数`，当前八球比赛奖励 40 珠，不另退押注；增加候选数不会将奖励翻倍。开赛锁定选择并收起完整押注面板，仅显示自己的候选球，余额不足禁止开赛，结算只执行一次。账户存储升级为 v2，原 v1 的 100 珠账户保留但不再读取，首次使用新版从 1000 珠开始。

比赛中放弃、刷新或关闭后再打开视为中断，不退已付珠子。新一场会重新生成赛道并回到选择界面，不自动扣费。该账户为本地单机积分，尚无服务端账户或联机玩家系统。

旧版随机赛道保留了固定的层间衔接、落孔和 U 弯结构，只改变曲线、木钉、导流方向、柱位和路段材质。当前版又加入上述三边/四边回环和固定障碍组洗牌；每次加载或选择新一场均生成新种子。

押注逻辑可用 `node tools/check-betting.mjs` 验证。物理测试支持 `node tools/check-physics.mjs <比赛种子> <赛道种子>`，验证实际生成的赛道，不只验证固定模板。

### 历史版本：20 赛段与真实落孔

所有弹珠在 `z=40` 的同一条起跑线上，前后偏移取消，仅保留微小横向偏移与接触材质随机变化。起跑线增加可见标记。

赛道参数跨度为 524 个场景单位，包含宽坡起跑、双球漏斗、木钉迷阵、倾斜回转、三角导流、双路分叉、波浪与蛇槽、汇流争位、挡板圆柱、落阶回廊、木质落孔碗、下层双球窄桥、金属弯道、摆门与转轮、双路汇流、第二座木质落孔碗、下层加速、U 形回转、折返长坡和终点冲刺。参数距离用于比赛进度，并非实际弧长。

两个碗均由有真实中心空洞的环形碰撞网格构成，落孔半径 1.55，碗深 4.5；孔下有护筒和低 8 单位的承接赛道，依靠重力落球，不使用瞬移。护筒下端留出球径以上的横向出口高度，避免球落地后被困在筒内。形成上层、下层及第二承接层的连续比赛。

摆门和转轮使用真实铰链约束，由弹珠碰撞推动。护栏与导流布局留有旁路，避免必须推动机构才能完赛。

赛道增加陶瓷、橡胶、拉丝金属和复合材料表面，纹理按各自特性生成；两座漏斗碗均沿用本场选定的木材纹理。赛道地面、两侧护墙和漏斗碗碰撞静音，独立障碍物的撞击按材质发声。

三角导流块的底面不再参与渲染，底部埋入赛道；补齐贴图坐标、修正面朝向、采用独立面法线。碰撞采用封闭凸包，避免将可见单层三角面当作薄壁实体。阴影增加法线偏移，缓解阴影条纹。实际画面的闪烁修复效果仍需人工观察。

最下层新增半径 8 的完整 180 度 U 弯，之后赛道沿相反方向继续下降。排名、冲线判断与自动镜头均使用赛道进度参数，避免将世界坐标的反向移动判作倒退。护栏按各侧实际路径长度计算碰撞段，并使用连续网格渲染，减少护栏接缝穿出与重复面的闪烁风险。下降台阶采用平滑衔接。

## 验证及边界

### 材质碰撞声音与加速坡

玻璃弹珠互撞，或撞到木钉、旋转杆、金属及玻璃管等独立障碍物时播放实时合成的材质撞击声；赛道地面、两侧护墙、漏斗碗、起跑闸门和终点收集槽不发声。音量取决于法向撞击速度；两球碰撞只播放一次，弱碰撞和密集事件限流。当前不是实录音效，未进行实际试听。

起跑、迷阵后的过渡段和终点直道增加平滑额外落差，通过重力增强加速度；护栏朝向根据实际坡度计算。此次三个随机种子的测试中，所有弹珠完赛（约 33–54 秒），未检测到掉出底板或越过终点收集区。

这一历史版本采用连续弯曲斜坡、平滑下降台阶和下游出口浅碗。当时尚未实现上下层和中心落孔；这两项已在当前版本加入。
