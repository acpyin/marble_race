# Azure 云健五段赛事解说试听

这里的 `01-平述.ssml` 至 `05-夺冠.ssml` 是可审核的五种试听文本与候选控制值，不是最终语音参数。

微软官方列出的云健名称为 `zh-CN-YunjianNeural`，支持 `sports_commentary` 和 `sports_commentary_excited` 风格。播放器页面为 `试听.html`。

## 生成实际音频

在 PowerShell 中临时设置本机的 Azure Speech 区域与密钥，然后在 `outputs/web-game` 目录运行：

```powershell
$env:AZURE_SPEECH_REGION = '你的资源区域'
$env:AZURE_SPEECH_KEY = '你的语音资源密钥'
node tools/azure-yunjian-samples.mjs
Remove-Item Env:AZURE_SPEECH_KEY
```

脚本使用密钥请求 Azure TTS，生成五个 MP3 文件与可逐条播放的 `试听.html`。密钥不写入 SSML、HTML、JSON 或游戏前端。若未设置凭据，脚本只生成文本并明确标记音频待生成。

试听时重点比较：平述是否自然、追赶是否有渐进紧张感、反超和夺冠是否过度喊叫、漏斗段是否能让人听清排名依据。听完后再定最终语速、风格强度与音量，不把五段试验值直接接入实时播报。
